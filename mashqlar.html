    1. Kvadrat funksiya va uning grafigi

    Xossa 1 — umumiy ko'rinishi va uchi (vertex)

    y = ax² + bx + c (a≠0); uchi: x₀ = -b/(2a), y₀ = f(x₀). a>0 — shoxlari yuqoriga, a<0 — pastga.

    Namunaviy yechim

    1-misol: y = x² - 4x + 3 funksiyaning uchini toping.

    x₀ = -(-4)/(2·1) = 2 y₀ = f(2) = 4 - 8 + 3 = -1 Javob: uchi (2; -1), a=1>0 bo'lgani uchun shoxlari yuqoriga qaragan.

    Mustaqil ishlash uchun:

    1. y = 2x² - 8x + 5 funksiyaning uchini toping.
    2. y = -x² + 6x - 8 funksiyaning uchini toping.
    3. y = 3x² + 6x + 2 funksiyaning uchini toping.
    4. y = -2x² - 4x + 1 funksiyaning uchini toping.

    Xossa 2 — nollari (ildizlari)

    D = b² - 4ac. D>0 — ikkita ildiz x = (-b±√D)/(2a); D=0 — bitta ildiz; D<0 — haqiqiy ildiz yo'q.

    Namunaviy yechim

    1-misol: y = x² - 5x + 6 funksiyaning nollarini toping.

    D = 25 - 24 = 1 x = (5±1)/2 x₁ = 3, x₂ = 2

    Mustaqil ishlash uchun:

    1. x² - 7x + 12 = 0 tenglamani yeching.
    2. 2x² - 3x - 2 = 0 tenglamani yeching.
    3. x² + 4x + 4 = 0 tenglamani yeching.
    4. x² - 2x + 5 = 0 tenglamaning haqiqiy ildizlari bor-yo'qligini aniqlang.
    ↑ Mundarijaga qaytish

    2. Kvadrat tengsizlik va uning yechimi

    Xossa 1 — parabola (interval) metodi

    ax²+bx+c > 0 (yoki <0) ni yechish: ildizlarni topib, son o'qida a ning ishorasiga qarab intervallarni aniqlaymiz.

    Namunaviy yechim

    1-misol: x² - 5x + 6 > 0 tengsizlikni yeching.

    Ildizlar: x=2, x=3 (D=1) a=1>0 — ildizlar orasida manfiy, tashqarisida musbat Javob: x < 2 yoki x > 3

    Mustaqil ishlash uchun:

    1. x² - x - 6 < 0 tengsizlikni yeching.
    2. 2x² - 3x - 2 ≥ 0 tengsizlikni yeching.
    3. -x² + 4x - 3 > 0 tengsizlikni yeching.
    4. x² + 2x + 5 > 0 tengsizlikni yeching.

    Xossa 2 — D≤0 bo'lgan holatlar

    D<0 va a>0 bo'lsa ifoda barcha x uchun musbat; D=0 bo'lsa bitta nuqtadan tashqari bir xil ishorali.

    Namunaviy yechim

    1-misol: x² + 2x + 3 > 0 tengsizlikni yeching.

    D = 4 - 12 = -8 < 0, a=1>0 Demak ifoda barcha haqiqiy x uchun musbat Javob: x ∈ R

    Mustaqil ishlash uchun:

    1. -x² + 2x - 5 > 0 tengsizlikni yeching.
    2. x² - 6x + 9 > 0 tengsizlikni yeching.
    3. x² - 4x + 4 ≤ 0 tengsizlikni yeching.
    4. 4x² + 4x + 1 < 0 tengsizlikni yeching.
    ↑ Mundarijaga qaytish

    3. Trigonometrik ayniyatlar

    Xossa 1 — asosiy trigonometrik ayniyat

    sin²x + cos²x = 1; tgx = sinx/cosx; ctgx = cosx/sinx; tgx·ctgx = 1

    Namunaviy yechim

    1-misol: sinx = 3/5, x — I chetverakda. cosx va tgx ni toping.

    cos²x = 1 - 9/25 = 16/25 cosx = 4/5 (I chetverakda cosx>0) tgx = (3/5)/(4/5) = 3/4

    Mustaqil ishlash uchun:

    1. cosx = 12/13, x — I chetverak. sinx va tgx ni toping.
    2. sinx = 0.6, x — II chetverak. cosx ni toping.
    3. tgx = 3/4, x — I chetverak. sinx va cosx ni toping.
    4. sinx = -1/2, cosx > 0. tgx ni toping.

    Xossa 2 — qo'shish formulalari

    sin(a±b) = sina·cosb ± cosa·sinb; cos(a±b) = cosa·cosb ∓ sina·sinb

    Namunaviy yechim

    1-misol: sin75° ni toping (75°=45°+30°).

    sin75° = sin45°cos30° + cos45°sin30° = (√2/2)(√3/2) + (√2/2)(1/2) = (√6 + √2)/4

    Mustaqil ishlash uchun:

    1. cos15° ni toping (15°=45°-30°).
    2. sin105° ni toping.
    3. cos75° ni toping.
    4. tg15° ni tg(a-b) formulasi orqali toping.

    Xossa 3 — ikkilangan burchak formulalari

    sin2x = 2sinx·cosx; cos2x = cos²x - sin²x = 2cos²x - 1 = 1 - 2sin²x

    Namunaviy yechim

    1-misol: sinx=3/5 (I chetverak). sin2x va cos2x ni toping.

    cosx = 4/5 sin2x = 2·(3/5)·(4/5) = 24/25 cos2x = 1 - 2·(9/25) = 7/25

    Mustaqil ishlash uchun:

    1. cosx = 5/13 (I chetverak). sin2x va cos2x ni toping.
    2. sinx = 0.6 bo'lganda cos2x ni toping.
    3. tgx = 2 bo'lganda tg2x ni toping (tg2x = 2tgx/(1-tg²x)).
    4. sin30° dan foydalanib sin2·15° ni hisoblab tekshiring.
    ↑ Mundarijaga qaytish

    4. Arifmetik va geometrik progressiya

    Xossa 1 — arifmetik progressiya

    a(n) = a₁ + (n-1)d; S(n) = n/2·(2a₁+(n-1)d) = n/2·(a₁+a(n))

    Namunaviy yechim

    1-misol: a₁=3, d=4. a₁₀ va S₁₀ ni toping.

    a₁₀ = 3 + 9·4 = 39 S₁₀ = 10/2·(3+39) = 210

    Mustaqil ishlash uchun:

    1. a₁=5, d=-2. a₁₅ ni toping.
    2. a₁=-3, d=6. S₂₀ ni toping.
    3. a₄=25, d=3. a₁ ni toping.
    4. a₁=2, d=5. Qaysi had 47 ga teng?

    Xossa 2 — geometrik progressiya

    a(n) = a₁·q^(n-1); S(n) = a₁·(q^n-1)/(q-1), q≠1

    Namunaviy yechim

    1-misol: a₁=2, q=3. a₅ va S₅ ni toping.

    a₅ = 2·3⁴ = 162 S₅ = 2·(3⁵-1)/(3-1) = 2·242/2 = 242

    Mustaqil ishlash uchun:

    1. a₁=5, q=2. a₆ ni toping.
    2. a₁=100, q=0.5. S₄ ni toping.
    3. a₁=3, q=-2. a₄ ni toping.
    4. a₂=6, q=3. a₁ va S₅ ni toping.
    ↑ Mundarijaga qaytish

    5. Funksiya tushunchasi

    Xossa 1 — aniqlanish sohasi (domain)

    D(f) — x ning ruxsat etilgan qiymatlari: maxraj ≠ 0, juft ildiz ostidagi ifoda ≥ 0.

    Namunaviy yechim

    1-misol: f(x) = 1/(x-3) ning aniqlanish sohasini toping.

    x - 3 ≠ 0 => x ≠ 3 Javob: D(f) = (-∞;3)∪(3;+∞)

    Mustaqil ishlash uchun:

    1. f(x) = √(x-2) ning D(f) ni toping.
    2. f(x) = 1/(x²-4) ning D(f) ni toping.
    3. f(x) = √(4-x²) ning D(f) ni toping.
    4. f(x) = 1/√(x-1) ning D(f) ni toping.

    Xossa 2 — qiymatlar sohasi (range)

    E(f) — funksiya qabul qiladigan barcha y qiymatlari to'plami.

    Namunaviy yechim

    1-misol: y = x² funksiyaning qiymatlar sohasini toping.

    x² ≥ 0 barcha x uchun Javob: E(f) = [0;+∞)

    Mustaqil ishlash uchun:

    1. y = √x ning E(f) ni toping.
    2. y = -x²+4 ning E(f) ni toping.
    3. y = 1/x (x≠0) ning E(f) ni toping.
    4. y = |x|-2 ning E(f) ni toping.
    ↑ Mundarijaga qaytish

    6. Funksiya xossalari

    Xossa 1 — juft va toq funksiyalar

    f(-x)=f(x) — juft funksiya (OY o'qiga simmetrik); f(-x)=-f(x) — toq funksiya (koordinata boshiga simmetrik).

    Namunaviy yechim

    1-misol: f(x) = x²-3 juft funksiyami?

    f(-x) = (-x)²-3 = x²-3 = f(x) Javob: ha, juft funksiya.

    Mustaqil ishlash uchun:

    1. f(x) = x³ toq funksiyami?
    2. f(x) = x²+x — juft, toq yoki hech qaysimi?
    3. f(x) = |x| juft funksiyami?
    4. f(x) = 1/x toq funksiyami?

    Xossa 2 — o'suvchi va kamayuvchi funksiya

    x₁<x₂ bo'lganda f(x₁)<f(x₂) — o'suvchi; f(x₁)>f(x₂) — kamayuvchi.

    Namunaviy yechim

    1-misol: y=x² ning [0;+∞) dagi monotonligini aniqlang.

    x₁=1, x₂=2 (x₁<x₂) f(1)=1, f(2)=4, f(1)<f(2) Javob: [0;+∞) da o'suvchi.

    Mustaqil ishlash uchun:

    1. y=x² ning (-∞;0] dagi monotonligini aniqlang.
    2. y=-2x+5 o'suvchimi yoki kamayuvchimi?
    3. y=1/x ning (0;+∞) dagi monotonligini aniqlang.
    4. y=x³ ning R dagi monotonligini aniqlang.
    ↑ Mundarijaga qaytish

    7. Funksiya grafiklarini sodda almashtirishlar

    Xossa 1 — parallel ko'chirish

    y=f(x)+a — OY bo'ylab a birlik; y=f(x+a) — OX bo'ylab -a birlikka ko'chirish.

    Namunaviy yechim

    1-misol: y=x² grafigidan y=x²+3 grafigini qanday hosil qilish mumkin?

    y=x² grafigini OY o'qi bo'ylab 3 birlik yuqoriga ko'chiramiz.

    Mustaqil ishlash uchun:

    1. y=(x-2)² grafigini y=x² dan qanday hosil qilish mumkin?
    2. y=√x+1 grafigini tasvirlang.
    3. y=√(x-4) grafigini tasvirlang.
    4. y=x²-5 grafigini tasvirlang.

    Xossa 2 — cho'zish, siqish va aks ettirish

    y=k·f(x): k>1 — OY bo'ylab cho'ziladi, 0<k<1 — siqiladi; y=-f(x) — OX ga nisbatan aks ettirish; y=f(-x) — OY ga nisbatan aks ettirish.

    Namunaviy yechim

    1-misol: y=2x² grafigi y=x² dan qanday hosil bo'ladi?

    Har bir ordinata 2 marta orttiriladi — grafik OY bo'ylab 2 marta cho'ziladi (tikroq bo'ladi).

    Mustaqil ishlash uchun:

    1. y=0.5x² grafigi y=x² dan qanday hosil bo'ladi?
    2. y=-x² grafigini tasvirlang.
    3. y=-√x grafigini tasvirlang.
    4. y=(-x)² grafigi y=x² bilan bir xil ekanligini tushuntiring.

    8. Chiziqli va kvadratik modellashtirish

    Xossa 1 — chiziqli model

    y = kx + b; ikki nuqta orqali: k = (y₂-y₁)/(x₂-x₁)

    Namunaviy yechim

    1-misol: Taksi xizmati 5000 so'm boshlang'ich narx + har km uchun 2000 so'm oladi. 10 km uchun narxni toping.

    y = 2000x + 5000 x=10: y = 2000·10+5000 = 25000 so'm

    Mustaqil ishlash uchun:

    1. (1;3) va (3;9) nuqtalardan o'tuvchi to'g'ri chiziq tenglamasini tuzing.
    2. Ish haqi 2 000 000 so'm + soatiga 15000 so'm. 20 soatlik qo'shimcha ish uchun jami summani toping.
    3. Harorat 0-daqiqada 20°, har daqiqada 0.5° pasayadi. 40 daqiqadan keyingi haroratni toping.
    4. (0;4) va (5;14) nuqtalar orqali o'tuvchi chiziq tenglamasini tuzing.

    Xossa 2 — kvadratik model (eng katta/eng kichik qiymat)

    Kvadratik modelning ekstremal qiymati uchi (vertex) orqali topiladi: t₀=-b/(2a).

    Namunaviy yechim

    1-misol: Jism otilish balandligi h(t) = -5t²+20t (t — soniya). Eng katta balandlikni toping.

    t₀ = -20/(2·(-5)) = 2 h(2) = -5·4+40 = 20 metr

    Mustaqil ishlash uchun:

    1. h(t) = -4.9t²+30t — eng katta balandlik va vaqtini toping.
    2. P(x) = -2x²+40x-150 (foyda funksiyasi) — maksimal foydani toping.
    3. S(x) = x(20-x) — maksimal maydonni toping.
    4. h(t) = -5t²+15t+2 — maksimal balandlikni toping.

    9. Loyiha ishi. Munosabatlar va funksiyalar

    10. Sodda ratsional tenglamalar

    Xossa 1 — bitta kasrli tenglama

    Maxrajni noldan farqli deb, ikkala tomonni maxrajga ko'paytirib, chiziqli tenglamaga keltiramiz.

    Namunaviy yechim

    1-misol: (x+1)/(x-2) = 3 tenglamani yeching.

    x+1 = 3(x-2) x+1 = 3x-6 -2x = -7 => x = 3.5 Tekshirish: x≠2, mos keladi.

    Mustaqil ishlash uchun:

    1. (2x-1)/(x+3) = 1 tenglamani yeching.
    2. x/(x-1) = 2 tenglamani yeching.
    3. (3x+2)/(x-4) = 5 tenglamani yeching.
    4. (x-5)/(2x+1) = -1 tenglamani yeching.

    Xossa 2 — ikki kasrli tenglama

    a/x + b/(x-c) = d ko'rinishidagi tenglamani umumiy maxrajga keltirib, kvadrat tenglamaga olib kelamiz.

    Namunaviy yechim

    1-misol: 1/x + 1/(x+2) = 3/4 tenglamani yeching.

    Umumiy maxraj: x(x+2) 4(x+2)+4x = 3x(x+2) 8x+8 = 3x²+6x 3x²-2x-8 = 0, D=4+96=100 x = (2±10)/6 => x₁=2, x₂=-4/3

    Mustaqil ishlash uchun:

    1. 2/x - 1/(x-1) = 1 tenglamani yeching.
    2. 1/(x-2) + 1/(x+2) = 1/3 tenglamani yeching.
    3. 3/x + 2/(x+1) = 5 tenglamani yeching.
    4. 1/(x+1) - 1/(x-1) = 2/3 tenglamani yeching.
    ↑ Mundarijaga qaytish

    11. Sodda ratsional tenglamalar sistemasi

    Xossa 1 — o'rniga qo'yish usuli

    Bir tenglamadan bitta o'zgaruvchini ikkinchisi orqali ifodalab, boshqa tenglamaga qo'yamiz.

    Namunaviy yechim

    1-misol: {x+y=5; 1/x+1/y=5/6} sistemani yeching.

    y=5-x 1/x + 1/(5-x) = 5/6 5/(x(5-x)) = 5/6 => x(5-x)=6 x²-5x+6=0 => x=2 yoki x=3 Javob: (2;3) va (3;2)

    Mustaqil ishlash uchun:

    1. {x-y=1; 1/x+1/y=5/6} sistemani yeching.
    2. {x+y=7; 1/x-1/y=1/12} sistemani yeching.
    3. {2x+y=5; 1/x+2/y=3} sistemani yeching.
    4. {xy=6; 1/x+1/y=5/6} sistemani yeching.

    Xossa 2 — qo'shish/ayirish usuli

    1/x va 1/y ni yangi o'zgaruvchi sifatida qarab, tenglamalarni qo'shish yoki ayirish orqali yechamiz.

    A7. Ko'paytirish (karra) jadvali

    Xossa 1 — 1 dan 10 gacha karra jadvali

    Karra jadvali — 1 dan 10 (yoki 12) gacha bo'lgan sonlarning o'zaro ko'paytmalari jadvali; yodda tutish hisoblashni tezlashtiradi.

    Namunaviy yechim

    1-misol: 7 × 8 ni hisoblang (karra jadvalidan).

    7 × 8 = 56 Javob: 56

    Mustaqil ishlash uchun:

    1. 6 × 9 ni hisoblang.
    2. 8 × 8 ni hisoblang.
    3. 7 × 7 ni hisoblang.
    4. 9 × 9 ni hisoblang.

    Xossa 2 — jadvaldan amaliy foydalanish

    Katta sonlarni ko'paytirishda ham karra jadvali asosiy tayanch bo'ladi: masalan 60×70 ni topishda 6×7=42 dan foydalanib, oxiriga ikkita nol qo'shamiz.

    Namunaviy yechim

    1-misol: 60 × 70 ni karra jadvalidan foydalanib hisoblang.

    6 × 7 = 42 60 × 70 = 4200 Javob: 4200

    Mustaqil ishlash uchun:

    1. 40 × 80 ni hisoblang.
    2. 50 × 90 ni hisoblang.
    3. 6 × 12 ni hisoblang.
    4. 9 × 12 ni hisoblang.
