    1. Kvadrat funksiya va uning grafigi

    Formula 1 — kvadrat funksiyaning umumiy ko'rinishi va parabolaning uchi

    y = ax² + bx + c (a ≠ 0); parabolaning uchi: x₀ = -b/(2a), y₀ = f(x₀). a > 0 bo'lsa, parabolaning shoxlari yuqoriga, a < 0 bo'lsa, pastga yo'nalgan.

    Namunaviy yechim

    1-misol: y = x² - 4x + 3 funksiya grafigining uchini toping.

    x₀ = -(-4)/(2·1) = 2 y₀ = f(2) = 4 - 8 + 3 = -1 Javob: parabolaning uchi (2; -1); a = 1 > 0 bo'lgani uchun shoxlari yuqoriga yo'nalgan.

    Mustaqil ishlash uchun:

    1. y = 2x² - 8x + 5 funksiya grafigining uchini toping.
    2. y = -x² + 6x - 8 funksiya grafigining uchini toping.
    3. y = 3x² + 6x + 2 funksiya grafigining uchini toping.
    4. y = -2x² - 4x + 1 funksiya grafigining uchini toping.

    Formula 2 — kvadrat funksiyaning nollari (kvadrat tenglamaning ildizlari)

    D = b² - 4ac. D > 0 bo'lsa, ikkita ildiz bor: x = (-b ± √D)/(2a); D = 0 bo'lsa, bitta ildiz bor: x = -b/(2a); D < 0 bo'lsa, haqiqiy ildizlar yo'q.

    Namunaviy yechim

    1-misol: y = x² - 5x + 6 funksiyaning nollarini toping.

    D = 25 - 24 = 1 x = (5±1)/2 x₁ = 3, x₂ = 2 Javob: funksiyaning nollari 3 va 2.

    Mustaqil ishlash uchun:

    1. x² - 7x + 12 = 0 tenglamani yeching.
    2. 2x² - 3x - 2 = 0 tenglamani yeching.
    3. x² + 4x + 4 = 0 tenglamani yeching.
    4. x² - 2x + 5 = 0 tenglamaning haqiqiy ildizlari bor-yo'qligini aniqlang.
    ↑ Mundarijaga qaytish

    2. Kvadrat tengsizlik va uning yechimi

    Usul 1 — parabola (intervallar) usuli

    ax² + bx + c > 0 (yoki < 0) tengsizlikni yechish uchun kvadrat uchhadning ildizlarini topamiz va son o'qida a ning ishorasiga qarab kerakli oraliqlarni aniqlaymiz.

    Namunaviy yechim

    1-misol: x² - 5x + 6 > 0 tengsizlikni yeching.

    Ildizlar: x = 2, x = 3 (D = 1) a = 1 > 0, shuning uchun uchhad ildizlar orasida manfiy, ulardan tashqarida musbat Javob: x < 2 yoki x > 3

    Mustaqil ishlash uchun:

    1. x² - x - 6 < 0 tengsizlikni yeching.
    2. 2x² - 3x - 2 ≥ 0 tengsizlikni yeching.
    3. -x² + 4x - 3 > 0 tengsizlikni yeching.
    4. x² + 2x + 5 > 0 tengsizlikni yeching.

    Xossa 2 — D ≤ 0 bo'lgan hollarda kvadrat uchhadning ishorasi

    D < 0 bo'lsa, ax² + bx + c ifoda barcha x uchun a bilan bir xil ishorali (a > 0 da musbat, a < 0 da manfiy); D = 0 bo'lsa, ifoda x = -b/(2a) nuqtada nolga teng, qolgan barcha x da esa a bilan bir xil ishorali.

    Namunaviy yechim

    1-misol: x² + 2x + 3 > 0 tengsizlikni yeching.

    D = 4 - 12 = -8 < 0, a=1>0 Demak, ifoda barcha haqiqiy x uchun musbat Javob: x ∈ R

    Mustaqil ishlash uchun:

    1. -x² + 2x - 5 > 0 tengsizlikni yeching.
    2. x² - 6x + 9 > 0 tengsizlikni yeching.
    3. x² - 4x + 4 ≤ 0 tengsizlikni yeching.
    4. 4x² + 4x + 1 < 0 tengsizlikni yeching.

    3. Trigonometrik ayniyatlar

    Formula 1 — asosiy trigonometrik ayniyatlar

    sin²x + cos²x = 1; tg x = sin x/cos x (cos x ≠ 0); ctg x = cos x/sin x (sin x ≠ 0); tg x·ctg x = 1

    Namunaviy yechim

    1-misol: sin x = 3/5, x — I chorakdagi burchak. cos x va tg x ni toping.

    cos²x = 1 - 9/25 = 16/25 cos x = 4/5 (I chorakda cos x > 0) tg x = (3/5)/(4/5) = 3/4 Javob: cos x = 4/5, tg x = 3/4.

    Mustaqil ishlash uchun:

    1. cos x = 12/13, x — I chorakdagi burchak. sin x va tg x ni toping.
    2. sin x = 0.6, x — II chorakdagi burchak. cos x ni toping.
    3. tg x = 3/4, x — I chorakdagi burchak. sin x va cos x ni toping.
    4. sin x = -1/2 va cos x > 0. tg x ni toping.

    Formula 2 — qo'shish formulalari

    sin(a ± b) = sin a·cos b ± cos a·sin b; cos(a ± b) = cos a·cos b ∓ sin a·sin b

    Namunaviy yechim

    1-misol: sin 75° ni hisoblang (75° = 45° + 30°).

    sin 75° = sin 45°·cos 30° + cos 45°·sin 30° = (√2/2)(√3/2) + (√2/2)(1/2) = (√6 + √2)/4

    Mustaqil ishlash uchun:

    1. cos 15° ni hisoblang (15° = 45° - 30°).
    2. sin 105° ni hisoblang.
    3. cos 75° ni hisoblang.
    4. tg 15° ni tg(a - b) formulasi yordamida hisoblang.

    Formula 3 — ikkilangan burchak formulalari

    sin 2x = 2 sin x·cos x; cos 2x = cos²x - sin²x = 2cos²x - 1 = 1 - 2sin²x

    Namunaviy yechim

    1-misol: sin x = 3/5, x — I chorakdagi burchak. sin 2x va cos 2x ni toping.

    cos x = 4/5 sin 2x = 2·(3/5)·(4/5) = 24/25 cos 2x = 1 - 2·(9/25) = 7/25

    Mustaqil ishlash uchun:

    1. cos x = 5/13, x — I chorakdagi burchak. sin 2x va cos 2x ni toping.
    2. sin x = 0.6 bo'lsa, cos 2x ni toping.
    3. tg x = 2 bo'lsa, tg 2x ni toping (tg 2x = 2 tg x/(1 - tg²x)).
    4. sin 15° va cos 15° qiymatlaridan foydalanib, sin 30° = sin(2·15°) = 2 sin 15°·cos 15° tenglikni tekshiring.
    ↑ Mundarijaga qaytish

    4. Arifmetik va geometrik progressiya

    Formula 1 — arifmetik progressiyaning n-hadi va dastlabki n ta hadi yig'indisi

    aₙ = a₁ + (n-1)d; Sₙ = n/2·(2a₁ + (n-1)d) = n/2·(a₁ + aₙ)

    Namunaviy yechim

    1-misol: a₁=3, d=4. a₁₀ va S₁₀ ni toping.

    a₁₀ = 3 + 9·4 = 39 S₁₀ = 10/2·(3+39) = 210

    Mustaqil ishlash uchun:

    1. a₁=5, d=-2. a₁₅ ni toping.
    2. a₁=-3, d=6. S₂₀ ni toping.
    3. a₄=25, d=3. a₁ ni toping.
    4. a₁=2, d=5. Progressiyaning nechanchi hadi 47 ga teng?

    Formula 2 — geometrik progressiyaning n-hadi va dastlabki n ta hadi yig'indisi

    aₙ = a₁·qⁿ⁻¹; Sₙ = a₁·(qⁿ - 1)/(q - 1), q ≠ 1

    Namunaviy yechim

    1-misol: a₁=2, q=3. a₅ va S₅ ni toping.

    a₅ = 2·3⁴ = 162 S₅ = 2·(3⁵-1)/(3-1) = 2·242/2 = 242

    Mustaqil ishlash uchun:

    1. a₁=5, q=2. a₆ ni toping.
    2. a₁=100, q=0.5. S₄ ni toping.
    3. a₁=3, q=-2. a₄ ni toping.
    4. a₂=6, q=3. a₁ va S₅ ni toping.

    5. Funksiya tushunchasi

    Ta'rif 1 — funksiyaning aniqlanish sohasi

    D(f) — x ning barcha joiz qiymatlari to'plami. Masalan, kasrning maxraji ≠ 0, juft darajali ildiz ostidagi ifoda ≥ 0 bo'lishi kerak.

    Namunaviy yechim

    1-misol: f(x) = 1/(x-3) funksiyaning aniqlanish sohasini toping.

    x - 3 ≠ 0 => x ≠ 3 Javob: D(f) = (-∞;3)∪(3;+∞)

    Mustaqil ishlash uchun:

    1. f(x) = √(x-2) funksiyaning aniqlanish sohasini toping.
    2. f(x) = 1/(x²-4) funksiyaning aniqlanish sohasini toping.
    3. f(x) = √(4-x²) funksiyaning aniqlanish sohasini toping.
    4. f(x) = 1/√(x-1) funksiyaning aniqlanish sohasini toping.

    Ta'rif 2 — funksiyaning qiymatlar sohasi

    95. Eyler–Venn doiralari va kiritish-chiqarish formulasi

    Formula 1 — kiritish-chiqarish formulasi (ikki va uch to'plam)

    96. Nyuton binomi

    Formula 1 — Nyuton binomi formulasi va binomial koeffitsiyentlar

    (a+b)ⁿ = Σ Cₙᵏ aⁿ⁻ᵏ bᵏ (k = 0, 1, …, n). Yoyilmadagi hadlar soni n + 1. Umumiy had: Tₖ₊₁ = Cₙᵏ aⁿ⁻ᵏ bᵏ. Binomial koeffitsiyentlar yig'indisi 2ⁿ; ishoralari navbatma-navbat almashadigan yig'indi Cₙ⁰ − Cₙ¹ + Cₙ² − … = 0 (n ≥ 1). Paskal uchburchagi: har bir son o'zidan yuqoridagi ikki sonning yig'indisiga teng.

    Namunaviy yechim

    1-misol: (x + 1)⁴ yoyilmasida x² oldidagi koeffitsiyentni toping.

    x² qatnashgan had: C(4,2)·x²·1²; C(4,2) = 4·3/(1·2) = 6

    99. O'rtacha kvadratik chetlanish, tanlanma va xatolik chegarasi

    Xossa 1 — o'rtacha kvadratik chetlanish tarqoqlikni o'lchaydi

    O'rtacha kvadratik chetlanish (standart chetlanish) σ — qiymatlarning o'rta arifmetikdan o'rtacha qanchalik uzoqligini ko'rsatadi: σ = √(((x₁ − x̄)² + … + (xₙ − x̄)²)/n), bunda x̄ — o'rta arifmetik. Qiymatlar bir-biriga yaqin bo'lsa, σ kichik; tarqoq bo'lsa, σ katta. Barcha qiymatlarga bir xil son qo'shilsa, o'rta arifmetik siljiydi, σ esa o'zgarmaydi; barcha qiymatlar k ga (k > 0) ko'paytirilsa, σ ham k ga ko'payadi. SAT imtihonida odatda σ ni hisoblash emas, taqqoslash so'raladi.

    Namunaviy yechim

    1-misol: A = {10; 11; 11; 12}, B = {2; 8; 14; 20}. Qaysi ma'lumotlar qatorining standart chetlanishi katta?

    Ikkala qatorning o'rta arifmetigi 11 ga teng. B ning qiymatlari o'rtachadan ancha uzoqda → B ning σ si katta.

    Qoida 2 — tanlanma va xatolik chegarasi

    Tasodifiy tanlanma (har bir kishining tanlanish imkoniyati teng) natijasi butun guruhga tatbiq etiladi: taxmin = N · p%. Xatolik chegarasi ±m bo'lsa, haqiqiy qiymat (p − m)% dan (p + m)% gacha oraliqda bo'ladi. Tanlanma hajmi qancha katta bo'lsa, xatolik chegarasi shuncha kichik bo'ladi. Noxolis tanlanma (faqat ixtiyoriy qatnashchilar yoki faqat bitta guruh vakillari) asosida butun guruh haqida xulosa chiqarib bo'lmaydi.

    Namunaviy yechim

    2-misol: Maktabdagi 2000 o'quvchidan tasodifan tanlangan 100 tasi so'raldi, natija 35% ± 4%. Butun maktabda bunday o'quvchilar soni qaysi oraliqda bo'lishi kutiladi?

    35% ± 4% → 31%–39%; 2000 · 0,31 = 620 dan 2000 · 0,39 = 780 gacha.

    Mustaqil ishlash uchun:

    1. {5; 5; 5; 5} va {1; 5; 5; 9} qatorlaridan qaysi birining σ si katta?
    2. {20; 22; 24; 26} qatorining har bir qiymatiga 10 qo'shilsa, σ qanday o'zgaradi?
    3. So'rov natijasi 48% ± 3%. Haqiqiy qiymat qaysi oraliqda bo'ladi?
    4. 100 kishilik va 400 kishilik tanlanmalardan qaysi birining xatolik chegarasi kichikroq?
    5. {7; 7; 13; 13} qatorining standart chetlanishini toping.

    100. Diagrammalar: nuqtali, quti diagrammasi, gistogramma

    Ta'rif 1 — nuqtali diagramma va gistogramma

    Nuqtali diagrammada har bir nuqta — bitta qiymat: nuqtalar soni = ma'lumotlar soni, eng baland ustun = moda, o'sish tartibida joylashtirilganda o'rtada turgan qiymat = mediana. Gistogrammada har bir ustun shu oraliqqa tushgan qiymatlar sonini (chastotani) ko'rsatadi; medianani topish uchun chastotalarni ketma-ket qo'shib boring va (n+1)/2-qiymat qaysi oraliqqa tushishini aniqlang.

    Namunaviy yechim

    1-misol: Nuqtali diagrammada 1 qiymati 2 marta, 2 qiymati 5 marta, 3 qiymati 3 marta uchraydi. Medianani toping.

    Jami 10 ta qiymat; o'sish tartibida 5- va 6-qiymatlarning ikkalasi ham 2 ga teng → mediana (2 + 2)/2 = 2.

    Ta'rif 2 — quti diagrammasi

    Quti diagrammasi beshta son bilan beriladi: eng kichik qiymat, birinchi kvartil Q1, mediana, uchinchi kvartil Q3, eng katta qiymat. Quti Q1 dan Q3 gacha cho'zilgan va ma'lumotlarning taxminan 50% ini o'z ichiga oladi. Kvartillararo kenglik IQR = Q3 − Q1, kenglik (qamrov) = eng katta − eng kichik qiymat. To'rtta bo'lakning har biriga ma'lumotlarning taxminan 25% i to'g'ri keladi. Quti uzun bo'lsa, tarqoqlik katta.

    Namunaviy yechim

    2-misol: Eng kichik qiymat 4, Q1 = 7, mediana 10, Q3 = 14, eng katta qiymat 20. IQR va kenglikni toping.

    IQR = 14 − 7 = 7; kenglik = 20 − 4 = 16.

    Mustaqil ishlash uchun:

    1. Nuqtali diagrammada 3 qiymati 4 marta, 4 qiymati 1 marta, 5 qiymati 2 marta uchraydi. Moda va medianani toping.
    2. Quti diagrammasida Q1 = 12, Q3 = 20. Ma'lumotlarning taxminan necha foizi 12 dan 20 gacha oraliqda joylashgan?
    3. Gistogrammada chastotalar: 0–10 oraliqda 3 ta, 10–20 oraliqda 7 ta, 20–30 oraliqda 2 ta. Mediana qaysi oraliqda yotadi?
    4. Quti diagrammasida eng kichik qiymat 5, eng katta qiymat 25. Kenglikni toping.

    101. Sochilma diagramma va eng yaxshi moslik chizig'i

    Xossa 1 — eng yaxshi moslik chizig'i nimani bildiradi

    Eng yaxshi moslik chizig'i y = mx + b: m (burchak koeffitsiyenti, qiyalik) — x bir birlikka oshganda y ning o'rtacha o'zgarishi; b — x = 0 dagi bashorat. Bashorat qilish uchun x ning qiymatini qo'yib, y ni hisoblang. Nuqta chiziqdan yuqorida bo'lsa, haqiqiy qiymat bashoratdan katta; qoldiq = haqiqiy qiymat − bashorat.

    Namunaviy yechim

    1-misol: y = 3x + 12 (x — tayyorgarlik soatlari, y — ball). x = 5 dagi bashoratni toping. (5; 30) nuqta chiziqqa nisbatan qayerda joylashgan?

    y = 3·5 + 12 = 27; 30 > 27 → nuqta chiziqdan yuqorida, qoldiq 30 − 27 = +3.

    Formula 2 — ikki nuqtadan o'tuvchi to'g'ri chiziq tenglamasi

    m = (y₂ − y₁)/(x₂ − x₁), b = y₁ − m·x₁. Desmos'da jadvalga nuqtalarni kiritib, y₁ ~ mx₁ + b deb yozsangiz, m va b avtomatik hisoblanadi (qarang: Desmos darslari, 5-dars).

    Namunaviy yechim

    2-misol: To'g'ri chiziq (2; 11) va (6; 23) nuqtalardan o'tadi. Uning Oy o'qi bilan kesishish nuqtasini (b ni) toping.

    m = (23 − 11)/(6 − 2) = 12/4 = 3; b = 11 − 3·2 = 5. Demak, y = 3x + 5, chiziq Oy o'qini (0; 5) nuqtada kesadi.

    Mustaqil ishlash uchun:

    1. y = −2x + 40 bo'lsa, x = 8 dagi bashoratni toping.
    2. y = 1,5x + 4 tenglamada qiyalik nimani bildiradi?
    3. Chiziq y = 4x + 1, nuqta (3; 10). Qoldiqni toping.
    4. (1; 7) va (4; 16) nuqtalardan o'tuvchi to'g'ri chiziq Oy o'qini qaysi nuqtada kesadi?
